## なにがすごいの？（自称）

### 📂 フォルダを 1 個放り込むだけ。あとは寝てて
「あのファイルどこだっけ……」と Finder の奥地を遭難する時代は、もう終わり。<br>
ルートフォルダを差し出した瞬間、中の Markdown をツリーに**全部ぶちまけて**くれます。次回からはワンタッチで復帰。許可ダイアログは、二度と顔を見せません。さようなら。

### 🔍 「あれ、どこに書いたっけ？」← 1 秒で成仏します
- **ファイル名検索**：ツリーがシュンと縮みます。気持ちいい。
- **中身全文検索**：本文の隅っこに書いた走り書きまで、グレップで引きずり出します。逃げ場なし。

### 🕸 リンクのつながりを、ぜんぶ可視化（自分の脳内宇宙が見える）
`[[wiki link]]` や `[](relative/path.md)` を解析して、ファイル同士の関係を**グラフで可視化**。<br>
「このメモ、誰から参照されてるの？」が一目瞭然。**自分の思考の絡まり具合**に、ちょっと引きます。

### 🕰 Git に、もう一度息を吹き込みます（電撃ピリピリ）
ルートが Git リポジトリなら、勝手に連携が始まります。気が早い。
- ツリーに **変更ステータス**（M / A / D / R / Untracked）をバッジでペタペタ。
- **タイムマシン**ボタンで、過去コミットの中身に飛べます。`git log --follow` 対応なので、**リネームの川**もスイスイ遡ります。鮭。

### 🪟 仕事の "横にそっと置ける" ビューア（邪魔しません、たぶん）
- **透明度調整**：ターミナルやエディタの上に**ふわっと**重ねて、メモを透かしながら作業。半透明の親切。
- **常に最前面**：チェックリストを画面の隅に**ずっと貼っとく**ヤツ。剥がれません。
- **フォーカスで自動再読込**：別エディタで保存 → 戻ってくる → もう最新。何もしなくていい。最高だね？

### 💧 何を投げ込まれても、たぶん読みます
- Finder から「このアプリで開く」、はい、対応。
- **VSCode のエディタタブからのドラッグ**、Finder ドロップ、外部からの D&D、**ぜんぶ受け止めます**。キャッチャー気質。
- ルート外のファイルを投げ込まれても、外部タブで開きます。あとから「ねえ、ここを親フォルダにしない？」と聞いてくれる、押しつけがましくない優しさ。

### ✨ Markdown の "気持ちいい" を全部のせ（盛りすぎ注意）
- GFM 相当のテーブル / 取り消し線 / **タスクリスト** / 見出しアンカー
- **highlight.js** でシンタックスハイライト（コードが急に色気づく）
- **Mermaid** 図表のレンダリング。フローチャートは **React Flow** でぐりぐり動きます。
- 相対パス画像も `.md` へのリンクも、ちゃんと解決。**気が利く**。

### 🎛 こだわり派のための設定モリモリ
テーマ（システム / ライト / ダーク）、フォントサイズ、行の高さ、読み幅、コードの折り返し、追加拡張子（YAML / JSON…）。<br>
**ぜんぶ localStorage に保存**するので、次回もあなたの城のまま。引っ越し不要。

## インストール

### 配布版（macOS）
[Releases](https://github.com/kasa-umbrella/markdown-explorer/releases) から `.dmg` をダウンロードして、`/Applications` にドラッグするだけ。

> 署名なし配布なので、初回起動時には `xattr -dr com.apple.quarantine /Applications/markdown-explorer.app` で隔離属性の解除が必要なことがあります。

### ソースからビルド
```bash
git clone https://github.com/kasa-umbrella/markdown-explorer.git
cd markdown-explorer
npm install

# 開発モード（HMR 付き）
npm run dev

# 配布用 DMG を作る
npm run dist

# ローカルの /Applications に焼き直す（macOS, Apple Silicon）
npm run install:local
```

## 使い方

### 1. フォルダを選ぶ
起動するとフォルダ選択画面。読みたいフォルダを 1 つ選ぶだけ。<br>
**選んだフォルダは記憶される**ので、次回起動時は自動で開きます。

### 2. ツリーから開く
左サイドバーのツリーから、好きなファイルをクリック。
- **シングルクリック**：プレビュー（ピンなしタブ）。
- **ダブルクリック**：ピン留めタブで固定。

### 3. 検索する
左上の検索バーの下にある **「名前」 / 「中身」** トグルで切り替え。
- **名前**：ツリーを絞り込み表示。
- **中身**：全ファイルの本文をグレップ。

### 4. リンクを辿る、グラフで眺める
プレビュー内のリンクをそのままクリックすれば、別ファイルにジャンプ。<br>
ツールバーの **🕸** ボタンで**リンクグラフ**を表示。ノードをタップすればそのファイルへ。

### 5. Git の中を覗く
- ツリーには変更ファイルのバッジが自動で出ます。
- プレビュー上部の **🕰** ボタンで**タイムマシン**を開き、過去コミットの内容を切り替え表示。

### 6. 設定を開く
右下の歯車ボタンから、ウィンドウ・テーマ・タイポグラフィ・拡張子をカスタマイズ。

## キーボードショートカット

| キー | 動作 |
| :-- | :-- |
| `⌘ + [` / `⌘ + ]` | アクティブタブ内で **戻る / 進む** |
| `⌘ + Shift + [` / `⌘ + Shift + ]` | **前 / 次のタブ**へ |
| `⌘ + 1` 〜 `⌘ + 9` | **N 番目のタブ**へジャンプ |
| `⌘ + W` | アクティブタブを閉じる（タブが無くなったらウィンドウを閉じる） |
| `⌘ + R` | アクティブタブの内容をディスクから**再読込** |

トラックパッドの **2 本指スワイプ**でも、戻る／進むができます。

## 対応している拡張子

デフォルトで以下を「ビューアブル」扱いします。<br>
追加したい拡張子は**設定モーダル**から自由に増やせます（小文字、ドット無し、カンマ／改行区切り）。

- Markdown: `.md` / `.markdown` / `.mdown` / `.mkd`
- 既定追加: `.yaml` / `.yml` / `.json`

Markdown 以外はシンタックスハイライト付きのコードブロックとしてレンダリングされます。

## 動作環境

- macOS（Apple Silicon を主に動作確認、Intel もビルド可）
- Electron 42 / React 19 / TypeScript / Vite
- Markdown レンダリング: `markdown-it` + `highlight.js` + `mermaid` + `@xyflow/react`
- ファイルアクセス: File System Access API（Electron の secure context 経由で永続化）

## 開発

```bash
# 型チェックつきビルド
npm run build

# Lint
npm run lint

# DMG を出力（release/ に出ます）
npm run dist
```

主要なディレクトリ：

```
src/
├── components/   # TreeView, Preview, GraphView, SettingsModal …
├── hooks/        # useDirectory, useTabs, useContentSearch, useSettings …
├── lib/          # markdown / mermaid / linkGraph / searchContent / paths
└── App.tsx       # ぜんぶの司令塔
electron/
├── main.ts       # メインプロセス（ファイル IPC、Git、ウィンドウ制御）
└── preload.ts    # contextBridge 経由のレンダラ API
```
